# Flappy Bird Clone (Unity - C#)

## Overview | Giới thiệu
This project is a clone of Flappy Bird developed using Unity and C#.  
Dự án tập trung vào xử lý vật lý và va chạm.

## Features | Chức năng
- Gravity-based movement | Chuyển động theo trọng lực
- Obstacle generation (pipes) | Tạo ống cản
- Collision detection | Xử lý va chạm
- Score tracking | Tính điểm

## Technologies | Công nghệ
- Unity Engine
- C#

## How to Run | Cách chạy
1. Open project in Unity Hub  
2. Load scene chính  
3. Press Play để chơi  

## Key Concepts | Kiến thức sử dụng
- Physics simulation  
- Collision detection  
- Game loop
